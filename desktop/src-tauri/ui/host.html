Host a Performance

Share this laptop's bundled engine and projects with clients on the same network. Clients sign in with their own invited accounts.

  1. On the iPad, open the setup address in Safari and download the certificate profile.
  2. Install it in Settings → General → VPN & Device Management.
  3. Enable full trust for pr0former Performance CA in Settings → General → About → Certificate Trust Settings.
  4. Open the HTTPS performance address and sign in using an invited account.

Tauri clients can choose this laptop from Server → Local Network and approve its certificate fingerprint.
